# 📝 Notes Maker

https://asifsheik.github.io/Notes-Maker/ - A simple and interactive **Notes Maker** web application built using HTML, CSS, and JavaScript. This project allows users to create notes dynamically using popup boxes and overlay effects.

## 🚀 Features

* **Create Notes:** Easily create new notes using a popup box.
* **Overlay Effect:** Uses an overlay to display the note creation popup.
* **DOM Manipulation:** Dynamically creates and manages note elements using JavaScript DOM manipulation.
* **Interactive UI:** Simple and user-friendly interface.
* **Dynamic Updates:** Newly created notes are displayed instantly without reloading the page.

## 🛠️ Technologies Used

* **HTML5** – Structure of the application.
* **CSS3** – Styling, layout, and popup overlay effects.
* **JavaScript** – DOM manipulation and interactive functionality.

## 💡 How It Works

1. Open the Notes Maker application.
2. Click the Add Note button.
3. An overlay popup box appears on the screen.
4. Enter your note in the popup.
5. Submit the note to dynamically create a new note.
6. The note gets displayed on the main page using JavaScript DOM manipulation.
